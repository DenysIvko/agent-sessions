Quick tour

Your agents, at a glance

This dashboard shows sessions with activity today in your local timezone, plus saved favorites from earlier days. Archived sessions stay hidden.

The live indicator and countdown show automatic refresh every 3 seconds. A warning means a source is unavailable; its last successful update stays visible.

Browse this guide without changing any sessions. Close it at any time, then use Help to return.

Anonymous product usage is shared with PostHog by default. Session contents, titles, projects and paths stay on your device. Use Privacy in the dashboard or Usage Analytics in the tray menu to turn sharing off.

Check progress

Click a status tile to filter the cards. Click it again to remove that filter. The bar underneath shows how the sessions are split by status.

A spinning icon means work is running. Completed, Stopped, Failed and Inactive describe different outcomes; inactive does not mean successful.

Read and Unread reflect the source's read state where available. Cards show the latest run duration and recent activity. Running work comes first, then unread results, then the most recent activity.

Find a session

Use the source chips for Codex, Claude Code or Antigravity, the project chips for a workspace, and the type menu for Chat or Scheduled sessions.

Search by title, project, branch or ID. Press / to focus search, or Escape while searching to clear it.

Filters work together. Clear filters resets them. Counts on tiles and chips describe the full Today + Favorites collection, or your favorites when that view is selected.

Recognize and open a card

The source badge names the agent app. The project label and branch show where the work belongs. Session and project colors come from their IDs, so they stay consistent after refresh.

Click a card or its Open button to return to Codex or the Claude desktop app. Those apps must be installed to handle the link.

For Antigravity, Copy resume command copies its conversation command. Paste it into your terminal with the Antigravity CLI installed. Hover an ID to see its full value.

Save it or clear it away

Click the star to keep a session across days. Favorites shows only starred sessions. Remove the star when you no longer need the reminder.

Archive hides a session from every Agent Sessions view, including Favorites, and persists after restart. It does not stop a running agent.

Source archival is best effort. Even if the source app refuses, the session stays hidden here. There is currently no Restore button in this client.

Use the compact tray

Click the macOS menu bar icon or Windows system tray icon. New opens by default with running work and finished results awaiting review. All includes today's activity and saved favorites; Favorites keeps your starred sessions across days.

Search narrows the selected tab. Each row has a source, project, running indicator, star and archive action. Open a finished result to review it; on macOS you can also right-click a row to mark it reviewed.

Open Web Dashboard returns to this larger view. Help reopens this guide.

Notifications and updates

A completion sends an OS notification without opening the tray. Right-click the tray icon to toggle completion notifications. OS notification permissions and Focus or Do Not Disturb settings can affect visible banners.

On macOS, the Notifications button also opens options for a test notification and system settings.

The tray menu offers Check for Updates, or Download Update when a newer release is ready. Checks run automatically; downloading and installing are your choice. Reinstalling preserves favorites and archives. Quit stops this app, not your coding agents.

Usage analytics

Help improve Agent Sessions by sharing anonymous product events with PostHog. Sharing is on by default and uses a random installation ID.

Events describe features used, agent source, app version and operating system. We do not send session contents, titles, session IDs, project names, file paths, search text or credentials. No screen recording or automatic click capture is used.
